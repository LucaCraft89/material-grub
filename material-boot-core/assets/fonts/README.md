# Google Sans Flex

`GoogleSansFlex-VF.ttf` is an **unmodified copy** of the variable font published by Google
(name table: `Version 5.000;[cedf1e9]`, downloaded 2026-11-16 from
`ofl/googlesansflex/GoogleSansFlex[ROND,opsz,slnt,wdth,wght].ttf` in https://github.com/google/fonts; only the file
name was shortened, because square brackets break shell globs).

- Licensed under the **SIL Open Font License, Version 1.1** ([OFL.txt](OFL.txt), copied verbatim from upstream).
  No Reserved Font Name is declared.
- Upstream: https://github.com/google/fonts/tree/main/ofl/googlesansflex

**Derivatives.** The bitmap `.pf2` fonts used by GRUB (`MG-Label`, `MG-Raw`) are generated from instances of this font.
Format conversion and instancing make them *Modified Versions* under the OFL: they remain under the OFL, carry the
same copyright notice, and are named neutrally. They are installed together with `OFL.txt` in
`/usr/share/material-grub/fonts` and in the theme directory.

This project is **not affiliated with or endorsed by Google**. Set `GSF_FONT=/path/to/other.ttf` to build with a
different copy of the font.
