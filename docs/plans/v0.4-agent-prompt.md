## GRUB facts learned the hard way
- No animation, no runtime recolour; `boot_menu` only draws whole items; one full-screen baked scene per entry is used as the item icon; `image` ignores width/height (pre-scale files); boot_menu icons are scaled to icon_width/height; GRUB draws the FIRST-declared component on top; theme colours are global (countdown/raw-name colours are neutral).
- `blscfg` ignores --path here; BLS mirrors live outside /boot/loader on ostree; blscfg skips ids already created at that menu level; Debian/Ubuntu GRUB has no blscfg.mod (CI boot job therefore runs in a Fedora container).
- PF2 fonts must NOT contain "Google" or "GSF" in names (trademark terms); keep OFL files and the "not affiliated with Google" line verbatim. SVG rasterising uses rsvg-convert (no ImageMagick dependency).
