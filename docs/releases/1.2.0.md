# Material GRUB 1.2.0

**This release removes the `material-grub` command and the graphical editor from this package.** By semantic versioning that is a breaking change; it ships as 1.2.0 on the maintainer's decision. Your settings, colours, names, icons, presets and entry order are kept.

| before | now |
|---|---|
| `material-grub apply`, `doctor`, `preview`, `ventoy`, `uninstall` | `material-boot grub apply`, `doctor`, `preview`, `ventoy`, `uninstall` |
| `material-grub colour`, `conf`, `presets`, `overrides` | `material-boot core colour`, `conf`, `presets`, `overrides` |
| `material-grub gui` | `material-boot ui` (now in material-boot-core, with the boot splash and Ventoy in the same place) |

Typing an old word prints where it went. The Material Boot installer (material-boot-core 1.2.0) removes the old command and the old editor from your machine, backing them up first. The hooks that run after a kernel change now call `material-boot grub apply`.

Needs **material-boot-core 1.2.0**. The full story, and the one installer screen that goes with it, is in the [material-boot-core 1.2.0 notes](https://github.com/LucaCraft89/material-boot-core/blob/main/docs/releases/1.2.0.md).

**Tested:** unit tests (including that nothing in the installer or the hooks still calls the old command); a real update from the released 1.1.1 bundle to this release in containers, including a kernel-change cycle with the new hook. **Not tested yet:** a real boot of this release on hardware; the package builds of this exact release outside CI.
